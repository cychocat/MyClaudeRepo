# MyClaudeRepo

Connected to my Claude.

This repository is my sandbox for working with [Claude Code](https://claude.com/claude-code). It's where I practise the everyday GitHub workflow with Claude's help: branching, committing, pushing and opening pull requests.

## About

I'm using this repo to learn how to ship code with Claude Code. Claude helps me connect to GitHub, write changes and open pull requests, while I review and decide what gets merged.

## Workflow

1. Create a branch for the change.
2. Make and commit the change.
3. Push the branch to GitHub.
4. Open a pull request into `main`.
5. Review and merge.
